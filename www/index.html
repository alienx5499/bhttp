Wire Architecture

Fixed 9-Byte Frame Header

Replaces HTTP/1.x delimiter parsing with deterministic fixed-width binary frames. 24-bit length supports payloads up to 16 MB with zero delimiter ambiguity.

Length (24b)
0x000025 (37B)
Type (8b)
0x01 (HEADERS)
Flags (8b)
0x05 (ALL)
Stream ID (31b + 1R)
0x00000001 (Stream 1)
Extensibility

Forward Compatible

Receivers encountering unknown v2 frame types (e.g. 0xFE) skip exactly Length bytes via streaming discard in $\mathcal{O}(1)$ memory without dropping the connection.

0xFE -> io::sink() [O(1)] Preserved
Header Compression

10-Entry HPACK Static Table

Common HTTP headers are pre-indexed to 1-byte identifiers (0x80 | Index), compressing pseudo-headers and common keys with sub-nanosecond L1 CPU cache lookups. Click any header to insert it into the studio:
